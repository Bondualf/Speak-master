# Speak-master

**Speak‑master** — это браузерное расширение для автоматического и точечного чтения текста голосом (TTS) с **синхронной подсветкой произносимых слов**. Оно идеально подходит для прослушивания статей, постов, комментариев и текста на веб-страницах.

---

## 🌟 Основные возможности

- **Умное чтение при наведении**  
  При наведении курсора на абзац, статью или комментарий слева от блока динамически появляется кнопка воспроизведения 🔊.

- **Запуск с задержкой**  
  Воспроизведение начинается после удержания кнопки мышью в течение **400 мс** — это исключает случайные срабатывания.

- **Синхронная подсветка слов**  
  Во время чтения каждое произносимое слово выделяется зелёным цветом (`#2ecc71`) в реальном времени.

- **Запуск колесиком мыши**  
  Нажатие средней кнопки мыши (Click‑wheel / MMB) на любом текстовом блоке или выделенном фрагменте мгновенно запускает озвучку.

- **Контекстное меню**  
  Выделите любой фрагмент текста на странице, нажмите правой кнопкой мыши и выберите пункт для озвучивания.

- **Гибкие настройки**  
  Во всплывающем окне можно регулировать:
  - скорость речи (слов в минуту),
  - тональность (pitch),
  - громкость,
  - а также выбирать голос из доступных системных и браузерных TTS‑движков.

---

## 🛠 Технические особенности

- **Платформа** — Manifest V2 (поддерживаются Google Chrome, Chromium, Supermium и другие браузеры на их основе).
- **Синтез речи** — используется нативный API браузера `chrome.tts`.
- **Инжектирование в подфреймы** — работает во всех iframe на странице благодаря параметру `"all_frames": true`.
- **Поддерживаемые площадки** — оптимизированная обработка селекторов для:
  - YouTube,
  - GitHub,
  - форумов (например, 4PDA),
  - новостных порталов,
  - а также стандартных HTML‑тегов: `<p>`, `<article>`, `<section>`, `<h1>`, `<li>`.

## ⚙️ Установка

1. **Скачайте** исходный код репозитория (или ZIP‑архив) и распакуйте в удобную папку.
2. Откройте страницу расширений в браузере:  
   `chrome://extensions/`
3. Включите **Режим разработчика** (переключатель в правом верхнем углу).
4. Нажмите **Загрузить распакованное расширение** и выберите папку с проектом.

Расширение готово к использованию! 🎉

## 🎮 Управление и всплывающее окно (Popup)

Во всплывающем меню доступны следующие параметры:

| Параметр | Описание |
|----------|----------|
| **Скорость** | Регулировка темпа воспроизведения от 0,1× до 10× (отображается в словах в минуту). |
| **Высота голоса** | Изменение тональности (pitch). |
| **Громкость** | Настройка уровня звука. |
| **Выберите голос** | Список всех доступных системных и браузерных TTS‑голосов. |
| **Показывать кнопку чтения** | Быстрое включение/отключение плавающей кнопки 🔊 слева от контента. |
| **Включить расширение** | Полная активация или деактивация работы всех скриптов расширения. |
